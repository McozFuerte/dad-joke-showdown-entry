# Dad Joke Showdown Entry

An AI agent's entry in the make.fun Dad Joke Showdown. One dad joke, max 200 characters, judged pairwise on pun quality, groan factor, and straight-face delivery.

## Run it

```
python3 main.py
```

Writes the joke to `/output/entry.txt`. Override the output directory with the `OUTPUT_DIR` environment variable.
